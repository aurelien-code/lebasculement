# Le Basculement

Simulation politique en temps réel : la France d’octobre 2026, vos cinq ans à l’Élysée, et toutes les issues possibles — de la VIe République à la monarchie, en passant par les régimes autoritaires.

**Jouer :** https://aurelien-code.github.io/lebasculement/

- 287 lois, 120 ministrables avec atouts et défauts, Assemblée et Sénat aux sièges réels
- Six forces à surveiller, une saison budgétaire complète, des alliances, des référendums, une campagne présidentielle
- Un mode « Dans l’opposition » pour conquérir l’Élysée

Le jeu tient dans un seul fichier, `index.html`. Les sauvegardes restent dans le navigateur de chaque joueur.
